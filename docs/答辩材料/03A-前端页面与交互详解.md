# 前端页面与交互详解

## 1. 前端定位

项目的前端不是单独部署的 Vue/React 应用，而是 JSP 服务端渲染页面。JSP 在 Tomcat 中执行，
最终输出普通 HTML、CSS 和 JavaScript 给浏览器。

```text
JSP 模板 + JavaBean 数据
        ↓ Tomcat 编译执行
HTML
        ↓
浏览器
```

## 2. 前端目录

```text
WebContent/
├── login.jsp
├── dashboard.jsp
├── admin/
├── teacher/
├── student/
├── WEB-INF/includes/
├── css/app.css
└── js/app.js
```

管理员、教师和学生页面分目录存放，便于角色权限和代码维护。

## 3. 页面布局

登录后页面由三部分组成：

```text
固定 Sidebar
+ 顶部 Topbar
+ 页面内容 Page Body
```

`sidebar.jsp` 根据 `loginUser.role` 输出不同菜单，因此三个角色看到的入口不同。

菜单隐藏只负责用户体验，真正权限由后端 Filter 保证。

## 4. Bootstrap

Bootstrap 用于：

- 栅格布局
- 按钮
- 表单控件
- Modal 弹窗
- Alert
- 响应式样式

项目仍有自己的 `app.css`，避免页面完全依赖 Bootstrap 默认风格。

## 5. 公共组件

### header.jsp

- HTML head
- viewport
- Bootstrap CSS
- 项目 CSS
- CSRF meta

### sidebar.jsp

- 角色菜单
- 当前页面高亮
- 未读消息数量
- 登录用户信息

### footer.jsp

- 公共确认 Modal
- Bootstrap JavaScript
- 项目 JavaScript

### pagination.jsp

通过 request 属性接收：

- `page`
- `pageSize`
- `total`
- `baseUrl`

并生成分页链接。

### status-badge.jsp

统一将业务状态转换成颜色徽章，避免每个页面重复判断。

## 6. 表单设计

页面表单主要包括：

- 登录表单
- 用户新增/编辑
- 课题发布/编辑
- 选题申请和审批
- 文档上传和审核
- 答辩安排
- 消息发送

表单 `name` 必须与 Servlet 的 `getParameter()` 一致。

例如：

```html
<input name="score">
```

对应：

```java
request.getParameter("score");
```

## 7. JavaScript 功能

`app.js` 提供统一交互：

- Toast 提示
- 密码可见性切换
- 删除确认
- 分数校验
- CSRF Token 注入
- URL 消息解析

业务页面还包含少量局部函数，例如打开审批 Modal、给隐藏字段赋值。

## 8. 前端数据来源

主要有三种。

### request 域

Controller 查询后：

```java
request.setAttribute("topics", topics);
```

JSP 读取并循环展示。

### Session

用于当前登录用户：

```jsp
User loginUser =
    (User) session.getAttribute("loginUser");
```

### AJAX JSON

统计页通过 `fetch()` 请求 `/admin/stats.action`，然后交给 ECharts。

## 9. 前端校验和后端校验

前端校验：

- required
- number min/max
- 文件 accept
- JavaScript 提示

这些都能被绕过，所以后端再次验证：

- 分数范围
- 文档阶段
- 用户权限
- 文件扩展名
- 课题名额

答辩时应说明“前端负责体验，后端负责可信规则”。

## 10. 响应式设计

当屏幕小于 768px：

- 侧边栏默认隐藏。
- 主内容取消左边距。
- 菜单按钮控制侧边栏。

课题卡片和统计卡片使用 CSS Grid 自动换行。

## 11. 前端安全

- EscapeUtil 转义用户文本。
- 使用 `textContent` 显示动态内容。
- CSRF Token 自动加入 POST 表单。
- 上传 input 限制常用文档类型。
- CSP 限制资源来源。

## 12. 前端答辩模板

> 前端采用 JSP 服务端渲染，结合 Bootstrap 和自定义 CSS 实现三角色后台布局，使用原生
> JavaScript 完成 Modal、Toast、表单确认、分数校验和 CSRF 注入。普通页面数据由 Servlet
> 放入 request 域后由 JSP 渲染，统计页面使用 fetch 请求 JSON 并通过 ECharts 绘图。前端
> 校验主要改善交互体验，关键权限和业务规则仍由后端验证。
