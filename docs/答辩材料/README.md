## 核心答辩观点

答辩时应始终围绕以下主线：

> 本项目以课程讲授的 JSP、Servlet、JavaBean、DAO、JDBC、Session、Filter 和 MySQL
> 为核心，采用服务端渲染的 MVC 架构。在课程 CRUD 案例基础上，增加了三角色权限、
> 选题事务、文档状态机、文件上传、Excel、统计图表和数据库约束。
