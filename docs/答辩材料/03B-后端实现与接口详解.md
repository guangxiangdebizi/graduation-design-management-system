# 后端实现与接口详解

## 1. 后端目录

```text
src/
├── controller/
├── bean/
├── dao/
├── dbutil/
├── filter/
└── util/
```

## 2. Controller

Servlet Controller 负责：

1. 接收 GET/POST。
2. 读取请求参数。
3. 获取 Session 用户。
4. 参数转换和基础校验。
5. 调用 DAO。
6. 设置 request 属性。
7. forward 或 redirect。

Controller 不直接编写大量 SQL。

## 3. JavaBean

Bean 是层之间传递的数据对象，遵循私有属性和 getter/setter。

例如 Topic：

- 数据库字段：id、title、teacherId、status。
- 页面扩展字段：teacherName、collegeName。

## 4. DAO

DAO 将数据访问集中到独立类：

```text
UserDao
TopicDao
SelectionDao
DocumentDao
...
```

优点：

- SQL 不散落在 Servlet。
- 查询可复用。
- Bean 映射集中。
- 事务逻辑可控。

## 5. SQLHelper

SQLHelper 封装 JDBC 公共步骤：

```text
获取连接
→ 创建 PreparedStatement
→ 绑定参数
→ 执行
→ 读取结果
→ 关闭资源
```

Druid 提供 DataSource 和连接池。

## 6. Filter

AuthFilter 是请求的统一入口：

```text
UTF-8
→ 安全响应头
→ 登录检查
→ 账号状态检查
→ 角色检查
→ CSRF
→ Controller
```

它将公共权限逻辑从各个 Servlet 中抽离。

## 7. Session

登录成功后：

```java
session.setAttribute("loginUser", user);
```

Filter 和 Controller 根据 User 的 id、role 判断身份。账号停用或角色改变后，Filter 会重新查询数据库并
使旧 Session 失效。

## 8. 接口分类

### 页面查询接口

返回方式：forward JSP。

- `/admin/user.action`
- `/teacher/topic.action`
- `/teacher/selection.action`
- `/teacher/document.action`
- `/student/topic.action`
- `/student/document.action`

### 写操作接口

返回方式：redirect GET 页面。

- 用户 CRUD
- 课题 CRUD
- 申请和审批
- 文档提交和审核
- 消息
- 答辩

### 数据/文件接口

- `/admin/stats.action`：JSON
- `/admin/export.action`：Excel
- `/download.action`：文件流

## 9. 事务业务

### 选题

SelectionDao 负责：

- 锁定学生和课题。
- 检查有效申请。
- 检查课题名额。
- 修改申请状态。
- 更新 selected_count。
- 满员关闭课题。

### 文档

DocumentDao 负责：

- 检查 approved 选题。
- 检查阶段顺序。
- 锁定当前文档。
- 保存旧版本。
- 更新当前版本。
- 清空旧评分。

## 10. 后端安全

- PreparedStatement
- BCrypt
- Session 角色
- Filter
- CSRF
- XSS 输出转义
- 文件扩展名白名单
- canonical path 防路径穿越
- 数据所有权检查
- 数据库唯一约束

## 11. 异常和结果处理

DAO 写操作返回影响行数或业务错误码，Controller 根据结果决定：

- 成功提示
- quota_full
- stage_locked
- forbidden
- error

只有数据库操作成功后才记录成功日志和发送通知。

## 12. 后端答辩模板

> 后端采用 Servlet Controller、JavaBean、DAO 和 JDBC 分层。请求先经过 AuthFilter 完成登录、
> 角色和 CSRF 校验，再进入 Servlet。Servlet 读取参数并调用 DAO，DAO 通过 SQLHelper 和
> Druid 访问 MySQL。普通查询封装为 JavaBean 后放入 request 并 forward JSP，写操作采用
> Post/Redirect/Get。选题审批和文档提交使用显式事务及行锁，数据库唯一约束作为最终兜底。
